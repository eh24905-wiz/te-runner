# CLAUDE.md

Doc and durable-knowledge rules for this repo family live in one place:
**`te-labkit-v2/CLAUDE.md`** — a sibling checkout, or
`github.com/wiz-training/te-labkit-v2`. Read it before writing any doc, README,
comment, commit message or PR body here.

Rules are not restated here: a copy drifts out of agreement with the canonical
file and nothing fails when it does.

Repo-local constraints — and nothing else — go below.
